Your encrypted workbook.

The password decrypts your workbook on this device. Changes are encrypted with AES-256-GCM before being saved to browser storage. GitHub Pages serves the application and encrypted starter; it does not receive your edits or sync them across devices.

Download an encrypted JSON backup regularly. It uses the workbook password. Import a backup to move between devices. Credential sheets cannot be exported as unencrypted CSV. Other CSV exports require confirmation because CSV is plain text. Older workbook backups can be imported and will be encrypted when saved.

API keys, passwords, and recovery codes are masked by default. Select a credential cell to reveal it briefly or copy it. The workbook locks after 5 minutes of inactivity and requires the password on each reload. There is no password recovery; retain a trusted backup and your password. This is client-side encryption, not a server account or a shared password manager.

Keyboard: arrows or Tab to move, Enter or F2 to edit, Escape to cancel, Ctrl/Cmd+Z to undo. Use the value bar to edit longer notes. Values are plain text; spreadsheet formulas are not executed.
